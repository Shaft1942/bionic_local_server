# Vérification des canaux stable et bêta

Date : 23 octobre 2026. Version préparée : `2.2.0-beta.1`, sur la base publiée `2.1.0` et des améliorations de lecture/paramètres.

## Comportements vérifiés localement

- Choix Stable par défaut, y compris sur une installation bêta ; migration des anciennes préférences, persistance atomique et réglage indépendant des vérifications automatiques.
- Filtrage des versions : stable exclut les préversions ; bêta accepte les bêtas numérotées et les stables plus récentes ; concordance tag, statut GitHub et canal du manifeste.
- Comparaison numérique des bêtas et passage vers la stable de même base, sans retour automatique à une ancienne version.
- Résultats des anciennes vérifications et téléchargements invalidés après changement de canal. Préférences bloquées pendant la préparation de l'installation ; installation bloquée pendant l'enregistrement d'une préférence.
- Installateur autonome : ZIP, manifeste et empreintes contrôlés ; parcours synthétiques `2.1.0 → 2.2.0-beta.1 → 2.2.0-beta.10 → 2.2.0`, sauvegarde exacte des sources et conservation des données synthétiques. Un second parcours utilise les ZIP réellement construits par le générateur.
- Navigateur à 320 et 1280 px : choix de canal pendant une vérification, échec de sauvegarde avec retour au choix persistant, vérification manuelle, retour à Stable depuis une bêta, clavier et absence de débordement ou d'appels externes. Toutes les API sont simulées.

## Publication et limites

La stable `v2.1.0` est conservée. Les tags `vX.Y.Z-beta.N` produisent des préversions GitHub sans déplacer la dernière stable ; un tag doit correspondre exactement au paquet et disposer de ses notes de version.

La stable 2.1.0 ignore les préversions et n'a pas le sélecteur : le premier passage à la bêta nécessite la [mise à jour manuelle avec sauvegarde](sauvegarde-mise-a-jour.md). Une installation bêta conserve Stable par défaut ; sélectionner Bêta permet les préversions suivantes.

Ce relevé local ne confirme ni publication GitHub, ni mise à jour d'une installation personnelle, ni migration réelle depuis 1.9.0, ni téléphone physique, lecteur d'écran, moteur Bionic ou génération ComfyUI. La borne minimale de compatibilité 1.9.0 est conservée du contrat antérieur.


## Préparation 2.2.1-beta.3 — 23 octobre 2026

Base : tag publié `v2.2.1-beta.2` (`a414e6e`), avec conservation des paramètres par section, des brouillons, de la lecture et des canaux de mise à jour. Le numéro de paquet est `2.2.1-beta.3` ; une archive locale ne constitue pas une publication GitHub.

Ajouts : recherche de serveur limitée à l'adresse saisie et aux ports locaux 8188/8000, diagnostic fichiers/nœuds, module mémoire téléchargeable avec session, nettoyage facultatif figé par demande. Les réglages de format 1/2 conservent le nettoyage ; une nouvelle installation le laisse désactivé. Sans nettoyage, les deux recettes retirent le nœud 99 et acceptent SaveImage sans sortie.

Preuves synthétiques : `test/comfy-settings.test.mjs` couvre les deux graphes sans module, la migration, le gel du choix, les dossiers manquants et les destinations autorisées. `test/v2-settings-http.test.mjs` couvre session/origine, diagnostic et téléchargement. `test/settings-ui.test.mjs` couvre annulation, persistance et réponses périmées. `scripts/browser-v2.mjs` rejoue serveur absent, fichiers manquants, activation du nettoyage impossible puis mode sans module à 320 et 1280 px ; `scripts/browser-settings.mjs` conserve les parcours globaux à 320, 390 et 1280 px.

Le scénario serveur existant échouait aussi sur la beta.2 intacte : le fichier synthétique réutilisé présentait parfois deux liens et était donc refusé par la protection d'édition. Les cas indépendants recréent désormais leur propre fichier au lieu de tronquer le précédent. Aucune protection du produit n'est assouplie.

Limites : aucun rendu, modèle, GPU, téléphone physique ni installation ComfyUI réelle n'est qualifié. Le diagnostic ne télécharge pas les poids et n'installe pas le module. Les recettes attendent toujours leurs noms de fichiers exacts. Aucune accélération mémoire n'est revendiquée.

Résultats exécutés : `npm run check` (109 sources), `npm test` (609 tests réussis), `npm run check:export` (205 sources autorisées), parcours navigateur V2 (320/1280 px, six diagnostics par viewport) et Paramètres (320/390/1280 px). Le détecteur de design signale seulement l'aperçu d'image caché sans `src`, préexistant et renseigné lors de l'ouverture d'un fichier ; aucune modification de cet aperçu.
