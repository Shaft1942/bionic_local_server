Images avec ComfyUI

Installation PC · partagé entre les conversations.

1. Trouver ComfyUI

Démarre ComfyUI sur le PC. Le compagnon se connecte à son serveur ; le téléphone n’a pas besoin d’accéder directement à ComfyUI.

Adresse vue depuis le PC qui héberge le compagnon. Exemple réseau : http://192.168.1.197:8188.

ComfyUI n’est pas trouvé ?

La recherche vérifie les ports 8188 et 8000 sur le PC du compagnon, ainsi que l’adresse saisie. Pour un autre port, copie l’adresse affichée par ComfyUI dans le champ ci-dessus.

Dans ComfyUI Desktop, vérifie les paramètres du serveur et son port, puis démarre le serveur local. Sur le même PC, conserve localhost : aucune ouverture du pare-feu ou exposition réseau n’est nécessaire.

Pour un autre PC, saisis son adresse IPv4 privée et son port. Son serveur doit autoriser les connexions du réseau privé. Une erreur de connexion peut aussi venir du port, du pare-feu ou d’un serveur arrêté ; elle ne prouve pas qu’une option est désactivée.

2. Vérifier le modèle d’image

Choisis une recette puis lance la vérification ci-dessous. Les fichiers attendus et leur dossier seront indiqués. Les poids ne sont pas inclus avec le compagnon.

Conserver permet de continuer une autre conversation, avec un risque de ralentir les images. Décharger libère la mémoire après la préparation des prompts ; les réponses texte attendent la fin du lot. Le modèle sera rechargé à la prochaine demande.

3. Choisir le nettoyage mémoire

Facultatif. Les modèles sont libérés après chaque image, y compris dans une série. Utile pour rendre de la mémoire à d’autres applications ou limiter les ralentissements entre rendus, notamment avec Krea 2. Les poids devront être rechargés à l’image suivante, qui peut donc être plus lente. Aucun gain de vitesse ni quantité de mémoire libérée n’est garanti.

Le nettoyage attend la fin du workflow et ne décharge pas Bionic. Désactivé : ComfyUI conserve sa gestion mémoire habituelle, aucun module supplémentaire n’est requis. Les réglages existants conservent leur ancien choix.

Installer le module mémoire facultatif
  1. Télécharger le module mémoire fourni sur le PC qui héberge ComfyUI.
  2. Copie le fichier dans le dossier custom_nodes de l’instance ComfyUI utilisée. Aucun paquet Python supplémentaire n’est nécessaire.
  3. Attends la fin des travaux, puis redémarre ComfyUI et relance la vérification. Le compagnon ne l’installe pas et ne redémarre pas ComfyUI.

Le module nécessite une sortie IMAGE sur SaveImage. Si ce lien n’est pas disponible sur ta version, laisse le nettoyage désactivé.

LoRA facultatifs et réglages avancés
Jusqu’à deux LoRA pour ce modèle

La liste vient de ComfyUI et comprend ses dossiers supplémentaires et ses téléchargements. Utilise des LoRA SDXL / Illustrious pour HassakuXL, ou Krea2 pour Krea2. Leur présence dans la liste ne garantit pas leur compatibilité.

Force 0 : LoRA désactivé. Les deux choix et leurs forces sont conservés séparément pour chaque modèle.

Après enregistrement, active aussi Images dans le menu Outils du message. Le diagnostic ne lance aucun rendu.

La chaîne Hassaku vers Krea2 reste expérimentale et n’est pas proposée comme workflow automatique.
