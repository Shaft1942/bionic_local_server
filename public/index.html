Comment fonctionne ce compagnon ?

Les historiques natifs restent lus sans modification. Les réponses écrites ici forment des conversations web distinctes sur ce PC.

Lorsque l’option de modification est cochée, le modèle dispose d’outils pour lire, créer et modifier les textes du dossier de travail de ce projet. Les actions sont enregistrées dans le chat. Les remplacements conservent une copie précédente que tu peux rétablir.

« Importer un fichier » copie les fichiers de ton appareil dans « Imports telephone », au sein du projet. Les formats lisibles sont joints au prochain message, dans la limite de quatre pièces jointes. Pour analyser une image PNG, JPEG ou WebP, choisis un modèle marqué Vision.

« Fichiers du projet » reste disponible pour consulter et éditer les fichiers manuellement. Le niveau de protection de la connexion est indiqué dans les paramètres.

    Images avec ComfyUI

    Le compagnon utilise ComfyUI installé sur le PC ou le réseau local. Les images apparaissent dans la conversation.

    Adresse vue depuis le PC qui héberge le compagnon. Exemple réseau : http://192.168.1.197:8188.

    Jusqu’à deux LoRA pour ce modèle

    La liste vient de ComfyUI et comprend ses dossiers supplémentaires et ses téléchargements. Utilise des LoRA SDXL / Illustrious pour HassakuXL, ou Krea2 pour Krea2. Leur présence dans la liste ne garantit pas leur compatibilité.

    Force 0 : LoRA désactivé. Les deux choix et leurs forces sont conservés séparément pour chaque modèle.

    Le modèle choisi conserve son workflow et ses réglages. Free Memory after Workflow (/free) libère les modèles ComfyUI après la sauvegarde de chaque image. Chaque message nécessite aussi l’option Images dans le menu Outils.

    La chaîne Hassaku vers Krea2 reste expérimentale et n’est pas proposée comme workflow automatique.
